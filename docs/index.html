Why it's different

Clinical trust first

Nisbat never invents a clinical fact. Every dose is traceable, every piece of parent-facing advice is curated (not machine-translated), and a signed discharge is immutable — editing one always opens a new revision.

⚖️

Explainable dosing

Weight → rule → calculated amount → formulation → volume → final dose — the full trace is always visible, never a black box. Manual override is allowed, but flags a warning past a substantial discrepancy.

🗣️

Bilingual by design

Urdu-only, Urdu + English, or English-only — chosen per discharge and overridable per medication or advice pack. Standard phrasing comes from a curated bilingual library, never a runtime translation.

📋

Governed content library

Advice packs, follow-up modules, dose rules, and more are authored once, reviewed, and reused — Faculty create and edit, Admin publishes. A discharge always keeps its own frozen snapshot.

🖨️

Print-first

A4 and Legal, an exact print preview that's the same component as the live print route — preview never lies about what actually prints. A pending-review card visibly says so until an SR signs it.

📈

WHO growth standards

Height/weight/BMI/MUAC Z-scores computed from the real WHO Child Growth Standards (2006) LMS parameter tables — not a rough approximation.

🔒

Real, self-hosted data

A real Postgres database (via Prisma), reachable from other devices on the same ward network, with role-checked authentication enforced server-side — not just hidden in the UI.

Content Library

Authored once, reused everywhere

Six governed content types share one lifecycle — Faculty/SR create and edit, Admin publishes, and only published content is ever offered for routine clinical selection.

Family education

Advice Packs

Danger signs, home care, bilingual bullets grouped into sections — applied selectively, per-bullet, never all-or-nothing.

Continuation of care

Follow-up Modules

A clinical follow-up visit template — service, timing, purpose, instructions — editable in place per discharge.

Rapid fill

Investigation Panels

A named group of tests that bulk-inserts result rows in one click — CBC, RFTs, LFTs, and more.

Dosing logic

Dose Rules

Per-kg or fixed dosing formulas with a live preview at sample weights — system rules are permanently locked, never editable.

Parent-facing wording

Frequency Phrases

How a dosing frequency prints for a parent — BD → "Twice daily" / "صبح و شام" — editable without a code deploy.

Rapid-fill chips

Vocabulary Lists

Exam/history/presenting-complaint chip sets and the diagnosis catalogue — edited a whole list at a time.

GitHub README Design notes

Nisbat will later be consolidated into a larger EMR (Nabz), but is built and usable standalone. Not a substitute for institutional clinical governance — a workspace to prepare and print a discharge, reviewed and signed on paper by a treating clinician.

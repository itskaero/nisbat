The first release of the **Nisbat Android app**, and a dedicated **TV app for the Chromecast**.

### Android app
- Its own phone design (not the website in a wrapper): Home, Quran, Namaz, Saman, Tasks, Azkar & tasbeeh, Sunein, News, Mausam, Bazaar, Tareekh & Kalam, Live TV and Settings.
- **Finds your Nisbat server on the Wi-Fi by itself.** The first time, the TV asks *"Allow this phone?"*: press OK once (or use the household PIN).
- **TV remote with no codes:** D-pad or swipe, play/pause, type on the TV, and "Show on TV" for whatever you're looking at.
- Prayer-time notifications, haptics, offline with the last synced data, and photo sharing to the TV's photo frame.

### TV app (served by your Nisbat server at `/screen`)
- Built for the Chromecast's Chrome 90: opens instantly, never reloads between screens, with smooth focus movement and a calm ambient screen.

### Install
1. Download **nisbat.apk** below on the phone and tap Install (Android asks once to allow installs from your browser).
2. Your Nisbat server must be updated to this version (rebuild the Docker containers) so the app can find and pair with it.
